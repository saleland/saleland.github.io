관리자 모드 (로컬 제어 센터)

매물을 등록·수정하고, JSON 파일로 다운로드하여 깃허브(saleland.github.io) 레파지토리의 data 디렉토리에 푸시할 수 있습니다.

깃허브(saleland.github.io) 연동 및 푸시 가이드

1. 아래 [JSON 파일 다운로드]를 클릭하여 저장된 매물 데이터를 다운받습니다.

2. 로컬 컴퓨터의 saleland.github.io 레파지토리 폴더 내 data/properties.json 경로에 덮어씁니다.

3. 터미널에서 아래 명령어를 입력하여 푸시합니다.

git add data/properties.json
git commit -m "매물 정보 업데이트"
git push origin main
